# 2026-09-08 修复与验证

本轮处理阅读、查词、缓存和路由中已定位的问题。修复与验证未改动用户数据库、文献及设置，未调用真实 AI。

## 修复

- 阅读页引用未定义的 `targetChapterId`，导致正文初始化失败；现在从已保存段落恢复章节，无记录时打开第一章。
- 快速切章时旧请求覆盖新章节；现在仅接受最近导航的响应，失败时清除旧正文。
- 阅读位置混入章节状态，影响进度计算；加载时过滤旧记录，保存时分开处理。
- 切章或返回文库时，防抖计时器取消导致最近进度丢失；现在离开前提交待保存快照，回看不撤销已读状态。
- 已打开词卡时点击另一个词，冒泡事件关闭新卡；现在阻止该点击冒泡。
- 连续查词旧响应覆盖新词、同词换上下文不刷新；现在取消旧请求并检查响应是否仍有效。
- 段评命中缓存缺少头像字段报错；补全新缓存并兼容旧缓存。
- 查词缓存混用不同句子与普通/展开模式，且缓存命中不累计查询次数；拆分缓存并更新计数。
- 生词义项为负数时误取末项；现在不返回无效义项。
- 上传 HTTP 失败未抛出错误；现在保留服务器错误并正确发送 multipart 数据。
- 页面兜底遮蔽健康检查、未知 API 返回 HTML，静态文件缺少目录边界检查；现在分别处理。

## 复跑

在项目根目录执行：

```sh
npm --prefix frontend run build
(cd backend && venv/bin/python -m unittest discover -s tests -v)
node --test frontend/tests/api.test.js
```

浏览器测试依赖 Playwright 和 Chrome。在单独终端启动 Vite：

```sh
npm --prefix frontend run dev -- --host 127.0.0.1 --port 5179
```

再运行：

```sh
node frontend/tests/reader.browser.cjs
```

若 Playwright 未安装在 Node 可解析的目录，可通过 `PLAYWRIGHT_MODULE` 指定模块绝对路径；`READER_TEST_URL` 可覆盖测试地址，`PLAYWRIGHT_CHANNEL` 可覆盖 Chrome 渠道。测试拦截所有 API，使用合成文档，不访问真实后端。
